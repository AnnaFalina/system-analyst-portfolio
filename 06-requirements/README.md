# Требования (выдержка)

## Функциональные

| ID | Требование | Приоритет | Критерий приёмки |
|----|-----------|-----------|------------------|
| I-01 | Просмотр статуса заказа клиентом | High | Клиент видит текущий статус своего заказа |
| I-02 | Онлайн-оплата при любом тарифе и способе получения | High | Кнопка «оплатить онлайн» доступна всегда |
| I-07 | Автовыявление невостребованных заказов | Should | Через 30 дней после `готов` присваивается `невостребован` |
| I-10 | Уведомления о статусах `готов`, `проблема` | High | Клиент получает SMS/push |
| I-09 | Редактирование статуса сотрудником | High | Доступ по роли |
| — | Блокировка выдачи при неполной оплате | High | Переход `готов → выдан` запрещён, если `SUM(payments) < amount` |

## Нефункциональные

| ID | Требование | Критерий |
|----|-----------|----------|
| I-16 | Соответствие 152-ФЗ | Данные клиента защищены |
| I-17 | Нагрузка 270 RPS | Система отвечает корректно |
| I-19 | Время отклика ≤ 5 сек | При обычной нагрузке |
| I-20 | MTTR ≤ 1 час | Восстановление после сбоя |
