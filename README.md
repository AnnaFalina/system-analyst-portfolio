## Контекст проекта (кратко)

Сеть химчисток вела заказы на бумажных бланках: данные терялись при перевозке,
клиенты не знали статус заказа, сотрудники тратили до 30% времени на сверку.
Спроектирована система: карточка заказа, статусная модель, автоматические
уведомления, онлайн-оплата, отчётность, учёт невостребованных заказов.
